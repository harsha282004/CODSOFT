## Setup

```bash
git clone https://github.com/harsha282004/CODSOFT.git
cd CODSOFT
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r Task1_Movie_Rating_Prediction/requirements.txt
```

Each project folder contains its own README with project-specific details.
